Mark-1 is a slackbot which work by telling him commands and will not work by his own until you write his command

commands can be found by typing '''/mark-1-help''' in slack

Other commands which i implemented 

/mark-1 - Show i little description of Mark-1

/mark-1-ping - SHow the latency of the bot 

/mark-1-time [option] currently this option have start and stop this is used to measure the time you spend to code more option will comming soon 

/mark-1-advice - show you a random advice the the command is called
